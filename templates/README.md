# Templates

Small reusable records for disciplined iteration:

- [Experiment](experiment-template.md): test a product hypothesis.
- [Scenario](scenario-template.md): define an objective and meaningful constraints.
- [Release](release-template.md): connect changes with verified evidence.

Replace prompts with evidence; leave unknown results marked **Not measured**.

## Refresh the complete runtime catalogue

After `npm run setup`, run `npm run catalog` from the repository root. The generator reads the game source and installed Lucide glyphs, then refreshes `specs/` and `images/icons/` with all 36 types. All numeric values are fictional balance specifications.
