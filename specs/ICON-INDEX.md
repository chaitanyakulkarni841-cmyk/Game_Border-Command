# Icon index

All 37 types have standalone SVG glyphs matching the app's UI icon map. 33 also have source atlas crops; the 4 remaining installations have no atlas crop. The PNG atlases are not edited or duplicated by this generator.

The atlas SVG wrappers reference the repository's existing PNG files. They are intended for inline SVG or standalone SVG browser contexts. External images inside an SVG can be blocked when the SVG is embedded as an image, including GitHub Markdown. Use the standalone glyphs for reliable GitHub table icons, and [the HTML catalog](unit-catalog.html) to inspect the actual atlas art.
