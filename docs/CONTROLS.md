# Quick player guide

**[Open Border Command](https://border-command.chaitanyakulkarni841.chatgpt.site)**

## Start in one minute

1. Start a scenario and read its objective.
2. Open **Forces & Build**, choose a unit and place it in an eligible friendly area.
3. Select your unit. Click open terrain to move, or an eligible detected enemy to attack.
4. Watch its order, readiness, ammunition and supply. Use supporting forces when a crossing or defence needs help.

## Core controls

| Action | Control |
| --- | --- |
| Navigate the map | Drag normally. |
| Bulk-select forces | Hold Cmd on Mac or Ctrl on Windows/Linux, then drag a selection box. |
| Inspect a friendly unit | Click it. |
| Move selected forces | Click an eligible destination. |
| Attack | Click an eligible detected enemy with suitable friendly forces selected. |
| Add units or structures | Use the pinned Forces & Build controls and placement preview. |
| Change area of focus | Use the named command views. |
| Pause or change pace | Use the visible simulation controls. |
| Follow action | Select the cinematic-follow option; use return-to-map to regain command view. |

Use the game's displayed hints for formation, numbered-group and route-queue modifiers. This guide does not assign shortcuts that have not been checked against the current UI.

## Read the situation

Highlighted rivers may require engineering support. Mountain hurdles and supply limitations affect route choices. Defence coverage uses abstract game distances. An unavailable command should explain the missing condition.

Save before leaving a longer scenario. If a browser restricts application fullscreen, use its fullscreen control. Touch and browser-specific fullscreen behaviour remain part of the manual validation plan.
