# Outcomes and next priorities

[Portfolio index](../README.md)

## Delivered artifacts

A public playable game, recorded development progression, a prepared source package and this product portfolio. The documentation connects user intent, interaction choices, technical constraints and verification gaps.

The recorded current release includes a larger world, faster movement, command views and pinned Forces & Build. These are implementation outputs. They are not evidence of increased engagement or improved usability.

## Priorities

| Order | Next step | Why now | Completion evidence |
| --- | --- | --- | --- |
| 1 | Import the prepared source, icons and complete generated catalogues. | Make this repository reproducible and resolve documentation gaps. | Source revision recorded; build/test steps run from a fresh checkout. |
| 2 | Observe five first-time players. | Test the central promise of intuitive play. | Task results, friction notes and limitations published. |
| 3 | Fix the most common core-loop failures. | Reduce confusion before adding content. | Repeat affected tasks with new participants. |
| 4 | Validate browser, GPU and touch behaviour. | Establish where the game is usable and responsive. | Device matrix and reproducible defects. |
| 5 | Tune travel time and scenario pacing. | A larger map can introduce waiting. | Scenario-specific observation and measured pacing. |
| 6 | Expand presentation and scenarios selectively. | Add variety after reliability and clarity are demonstrated. | Explicit hypothesis, cost and acceptance test for each addition. |

## Deferred choices

Multiplayer, cloud saves, a more advanced 3D battle view and a larger roster would increase implementation and support demands. They should follow evidence that the basic experience works.

## Evidence discipline

Report “implemented” separately from “tested,” and “tested” separately from “successful with players.” Retention, adoption and enjoyment remain open questions. Use the [experiment template](../templates/experiment-template.md) to record the next decision.
