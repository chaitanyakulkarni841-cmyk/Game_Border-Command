# Images and unit symbols

[Runtime icon index](../specs/ICON-INDEX.md) documents all 37 UI glyphs and the 33 available source-atlas references. Standalone glyphs under `icons/glyph/` match the app mapping and render in GitHub; the [Lucide license](icons/LUCIDE-LICENSE.txt) is included. Atlas wrappers under `icons/atlas/` reference the original PNGs in `game/public/assets/` without duplicating them.

The 13 SVGs directly under `icons/` are retained original documentation symbols for broad roles. They are not official platform drawings.

I have included four [actual gameplay captures](gameplay/README.md): the command map, Northern Command terrain, operation selection and the mission scoreboard. The gallery records their source and capture limits.
